# 03. GitHub 템플릿

> PR 본문이나 이슈를 작성할 때 아래 양식을 그대로 사용한다.

---

## Pull Request 템플릿

```markdown
## 📌 작업 내용
- [ ] 
- [ ] 
- [ ] 

## 📝 관련 이슈
- Resolved: #

## 🌱 참고 사항
- 
```

---

## Issue 템플릿 (기능 이슈)

```markdown
---
name: 기능 이슈
about: 새 기능 개발 이슈 생성
title: "[Feat] "
labels: ["feature"]
assignees: []
---

## ✨ 기능 요약

## 📌 작업 내용
- [ ] 
- [ ] 
- [ ] 

## 🌱 참고 사항
- 
```
